## Store command
- Get it with exactly this one Bash command (prints an absolute path, `C:/...` on Windows Git Bash). Run it once per task and paste the result into every brief:
  ```bash
  m=$(git rev-parse --path-format=absolute --git-common-dir 2>/dev/null) && m=$(dirname "$m") || m=$(pwd -W 2>/dev/null || pwd); h=$(cygpath -m ~ 2>/dev/null || echo ~); o="$h/.claude/orchestrator"; k=$(printf %s "$m" | tr A-Z a-z | sed 's/[^a-z0-9][^a-z0-9]*/-/g' | tr -d '\n' | tail -c 80); r=$(git config --get remote.origin.url 2>/dev/null | head -n 1 | tr A-Z a-z | sed -e 's|^[a-z][a-z0-9+.-]*://||' -e 's|^[^/]*@||' -e 's|/*$||' -e 's|\.git$||' -e 's|/*$||' -e 's/[^a-z0-9][^a-z0-9]*/-/g' | tr -d '\n' | tail -c 80); if [ -n "$r" ] && [ ! -d "$o/$k" ]; then k=$r; fi; echo "$o/$k"
  ```
- Without Bash (PowerShell only), run this instead; it prints the same path:
  ```powershell
  $m = $null; try { $m = git rev-parse --path-format=absolute --git-common-dir 2>$null } catch {}; if ($LASTEXITCODE -eq 0 -and $m) { $m = Split-Path $m -Parent } else { $m = (Get-Location).Path }; $o = ($HOME -replace '\\','/') + '/.claude/orchestrator'; $k = $m.ToLower() -replace '[^a-z0-9]+','-'; if ($k.Length -gt 80) { $k = $k.Substring($k.Length - 80) }; $u = $null; try { $u = git config --get remote.origin.url 2>$null } catch {}; $r = ''; if ($LASTEXITCODE -eq 0 -and $u) { $r = @($u)[0].ToLower() -replace '^[a-z][a-z0-9+.-]*://','' -replace '^[^/]*@','' -replace '/+$','' -replace '\.git$','' -replace '/+$','' -replace '[^a-z0-9]+','-'; if ($r.Length -gt 80) { $r = $r.Substring($r.Length - 80) } }; if ($r -and -not (Test-Path -PathType Container "$o/$k")) { $k = $r }; "$o/$k"
  ```
- Key rule (both shells): if `git config --get remote.origin.url` is set, the key comes from that URL, so every clone and worktree of the repo shares one store: drop the scheme (`https://`, `ssh://`) and any credentials (everything up to the last `@` before the first `/`), lowercase, drop a trailing `/` and `.git`. Otherwise (no remote) it comes from the path: main checkout = parent of the absolute git-common-dir (outside git: the current folder), lowercased. In both cases every run of characters outside `[a-z0-9]` becomes one `-` and the last 80 characters are kept. Backward compatible: whenever the path-based folder exists it is used (even if a remote-based folder also exists); the remote-based key is used only when the path-based folder does not exist (nothing is moved). Needs git 2.31+. Examples: `C:/Users/me/Projects/My App` (no remote) -> `C:/Users/me/.claude/orchestrator/c-users-me-projects-my-app`; remote `git@GitHub.com:Foo/Bar.git` or `https://user:token@github.com/foo/bar` -> `.../orchestrator/github-com-foo-bar`. Never print or store the raw remote URL (it may hold credentials).

## Manual commands
- `list`: show every `learned-*` lesson file with its lesson count and the lesson lines, in one compact block.
- `add <lesson>`: check it against "What counts as a lesson", then save it per SKILL.md (What counts as a lesson / save rules).
- `remove <lesson or line>`: delete that lesson file, or that one line inside a lesson, from `<store>/lessons/` via one `haiku-coder` delegation; confirm the exact target with the user first if more than one matches.
- `prune`: check every lesson against the current project (commands and files still exist, no duplicates, nothing contradicted by recent work), then merge, fix, or remove automatically and report what changed in one short block. `learned-errors` over 15 entries: remove the fewest-hit entries first (missing `hits:` = 0; ties: oldest date).
